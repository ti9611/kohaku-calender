プライバシーポリシー

最終更新日：2026年11月16日

1. 取得する情報

本アプリは、利用者本人のGoogle OAuth認証と許可に基づき、 Googleカレンダーの予定、日時、場所、説明など、 予定管理に必要な情報へアクセスします。

2. 利用目的

取得した情報は、利用者から依頼された予定の確認、登録、変更、 削除および通知を行う目的に限って使用します。

3. 情報の保存

Googleへの接続に必要な認証情報は、本アプリの実行環境で 適切な保護を行ったうえで保存します。 Googleカレンダーの情報を広告や販売目的で利用することはありません。

4. 第三者提供

法令に基づく場合を除き、取得したGoogleユーザーデータを 利用者の同意なく第三者へ販売または提供しません。

5. Google APIサービス

本アプリにおけるGoogle APIから取得した情報の利用および他のアプリへの転送は、 Google API Services User Data Policy（Limited Use要件を含む）に準拠します。

6. 連携の解除と削除

利用者はGoogleアカウントのセキュリティ設定から、 いつでも本アプリのアクセス権を取り消せます。 保存された認証情報の削除を希望する場合は、 OAuth同意画面に記載された開発者連絡先へ依頼できます。

7. ポリシーの変更

本ポリシーは、機能や法令などの変更に応じて更新されることがあります。 変更後の内容はこのページで公開します。
